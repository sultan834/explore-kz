# Explore KZ — Kazakhstan Travel Guide

## Topic
A responsive multi-page travel website about destinations and tours in Kazakhstan.

## Pages
1. Home
2. Destinations
3. Tours
4. Gallery
5. Contact

## Requirements demonstrated
- Semantic HTML5
- Navigation on all pages
- Headings, paragraphs, lists, links
- Pricing/tour table
- Contact/booking form
- Flexbox
- CSS Grid
- Relative/absolute positioning
- Media queries for tablet and mobile
- Bootstrap 5 grid and utility classes
- Responsive design

## Technologies
HTML5, CSS3, Bootstrap 5
